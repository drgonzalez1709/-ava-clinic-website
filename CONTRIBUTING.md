# Contribuir

1. Cree una rama descriptiva: `feature/nombre` o `fix/nombre`.
2. No incorpore datos identificables de pacientes.
3. Ejecute `python3 scripts/validate_site.py`.
4. Abra un Pull Request usando la plantilla.
5. Todo texto clínico, afirmación de resultados y oferta comercial requiere aprobación del director médico.
6. Los cambios se integran mediante revisión y preferiblemente `squash merge`.
