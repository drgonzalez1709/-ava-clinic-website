# Imágenes

Reemplace el marcador del retrato por una fotografía profesional aprobada del Dr. Rodney González, optimizada en WebP o AVIF. Añada también una portada social de 1200×630 px en PNG o JPG y actualice las etiquetas `og:image`. No publique fotografías de pacientes sin consentimiento específico, documentado y revocable.
